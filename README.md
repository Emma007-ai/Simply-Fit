# SIMPLY FIT – Workout Tracking Application  
A full CRUD fitness tracking web application built using Node.js, Express.js, MongoDB Atlas, and EJS.  
This project allows users to create, view, edit, and delete workout entries in a simple and clean interface.

---

## 🧩 Features

### 🏠 Home Page
- App name clearly displayed: **SIMPLY FIT**
- Logo displayed
- Description of what the app does
- Three feature cards

### 🗂 Workout Management (CRUD)
- **Create** a new workout  
- **Read** all workouts in a table  
- **View** a single workout  
- **Update** workout information  
- **Delete** a workout with confirmation
